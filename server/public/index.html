Render Server Deployment & Firebase Realtime Database Guide

How to deploy this server to Render and connect the Android phone

1. Deploy to Render

1. Push this project to GitHub.

2. In Render Dashboard, click New + -> Web Service.

3. Select your repository, set Build Command: npm install, Start Command: node server.js.

4. Your service URL will be: https://your-service-name.onrender.com.

2. Firebase Realtime Database (Optional Realtime Sync)

Add environment variable on Render: FIREBASE_DB_URL=https://YOUR-PROJECT-ID.firebaseio.com.

Data will automatically replicate to your Firebase Realtime Database.

3. Android Child App Configuration

In the AirDroid Android app on the child's phone, switch to AirDroid Kids mode and enter your Render URL:

https://your-service-name.onrender.com

The Android background service will immediately establish a persistent connection and relay telemetry, alerts, and remote commands.
